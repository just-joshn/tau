## Working workflows at this baseline

These workflows are functional in tau against deterministic loopback model fixtures or fake providers. Original comparisons are recorded separately by exact scenario.

1. **Local coding:** prompt → search/Read → complete model-visible file baseline → Edit/Write → further model round → answer → own session saved. Real UTF-8/UTF-16LE/BOM/newline files, permissions and stale content are exercised. The newest compiled CLI test streams Write input above1MiB, edits its tail and overwrites the large file.
2. **Large-file coding:** ordinary refusal/page → `allow_large` → counted full Read → mutation; same-reply large reads share claims and can page when room is exhausted. New write-size PTY verifies300KB Read→Edit, external tail change rejection, reread recovery, Edit→Write, mode preservation, clear/reset and clean exit.
3. **Controlled tools:** availability/deny/allow plus current permission mode → tool advertisement/dispatch → approved work or explicit error; print mode cannot interactively grant approval. Shell cancellation/nonzero status and search pagination are covered.
4. **Context continuation:** long or server-refused context → selected summary planning/fallback/repair → retained groups and restored files → main-model continuation → own save/resume. Manual compaction, clear and resume work interactively.
5. **Transport recovery:** fragmented stream or selected HTTP/body failure → source-backed bounded decision/counters → partial retention or provisional rollback → retry/JSON/configured model fallback → consistent history. Disposable original comparison `http-404-then-json-text` matches the selected result, error flag, request count, and 404-then-200 sequence. Live account behavior remains unverified.

6. **Ordinary MCP stdio:** explicit config → in-place discovery/real initialization → model advertisement → approved call → structured/image result → dynamic tools refresh → continuation → save/resume; default/explicit denial prevents server calls, and every fixture child exits. Tests cover legacy/modern envelopes, errors, cancellation, idle/hard deadlines, resource/audio/PDF projection and collisions. Six ordinary MCP differential cases are verified; the table’s broader policies remain open.
